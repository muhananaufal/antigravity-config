### Panduan Siklus Status & Klasifikasi Tiering
* `Tier 1 (Full RFC)`: perubahan arsitektur, aturan lintas-dokumen, atau perilaku Quality Gate.
* `Tier 2 (Mini RFC 1-Pager)`: koreksi lokal non-breaking, penyelarasan angka, tweak internal.
* `PROPOSED`: dalam perancangan/review — menunggu "Gasskan".
* `ACCEPTED`: disetujui user, siap/sedang dieksekusi.
* `IMPLEMENTED`: seluruh batch tuntas dan lolos Quality Gate.
* `SUPERSEDED`: digantikan RFC lebih baru (sertakan tautan penggantinya).
